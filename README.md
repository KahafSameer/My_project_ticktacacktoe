# Tic-Tac-Toe (Python + Tkinter)

A two-player Tic-Tac-Toe game with a **Tkinter** GUI: click cells to play, with win and draw detection and a restart option.

## Requirements

- Python 3 with Tkinter (included in standard Python installers)
- No external packages (`requirements.txt` is intentionally empty)

## Run

```bash
git clone https://github.com/KahafSameer/My_project_ticktacacktoe.git
cd My_project_ticktacacktoe
python main.py
```
